01 / Separate views

One list at a time.

The horizontal menu switches between Work, Personal, and Daily note. Each todo view uses the full width, showing five initially, expandable to ten or all. Newest additions stay first.

02 / Daily note

A place for each day’s notes.

A date picker and a freeform writing area, separate from your todos. The intended app lets you add notes by day and return to earlier dates. Saving and date navigation are not implemented in this mockup.

Planning artifact only. Telegram, Calendar, persistence, and hosting are deliberately outside this layout. No app code changed. System fonts; no network requests.
